# M15 경로 생성 상태

2026-09-07 PathShape01 화면의 체크포인트 11개를 반영했습니다.
`checkpoints.csv`는 화면에 표시된 소수점 셋째 자리 좌표를 그대로 보존합니다.

현재 `route.csv`와 `route.svg`는 체크포인트를 순서대로 직선 보간한
**형상 확인용 초안**입니다. 차선 중심을 따르는 주행용 경로가 아니며,
실주행 검증을 통과하지 않았습니다. 기존 8개 체크포인트 경로는 교체했습니다.

차선 그래프 경로 생성은 9번 체크포인트에서 실패합니다.
8→9번 사이 road 2810 / lane 1의 중심선에서 road_s가
136.92875064→136.43043086으로 진행할 때 좌표가
(1209.93826807, 581.34920163)→(1211.75843837, 581.40432260)으로
약 1.82m 되돌아갑니다. 해당 구간의 곡률 검사값은 약 6.272 1/m입니다.
단순 lane-snap 방식도 road_s 역진행 검사에 실패했습니다.

주행용 경로를 완성하려면 해당 지도 형상/샘플링 문제를 해결한 뒤
`tools/sync_vtd_scenario.py`로 재생성해야 합니다. 곡률 및 시작 위치
검사는 완화하지 않았습니다. VTD 원본 XML의 Ego 위치는 변경하지 않았습니다.
