# M15 경로 생성 상태

2026-09-09 PathShape01 화면의 체크포인트 10개를 반영했습니다.
`checkpoints.csv`는 화면에 표시된 소수점 셋째 자리 좌표를 그대로 보존합니다.

9번 (1311.713, 581.578)을 추가하고 기존 도착점을 10번으로 옮겼습니다.
시작점(1), 교차로 진입·진출 쌍(2→3, 4→5, 6→7, 8→9), 도착점(10)의
구조이므로 홀수 개 입력에서 발생했던 `checkpoint_rules_valid=false`가
해결되었습니다. 검사 규칙이나 공용 미션 생성 코드는 변경하지 않았습니다.

`route.csv`와 `route.svg`는 새 체크포인트를 차선 그래프로 연결한
전체 경로입니다. 2,284개 경로점, 길이 1,124.726m이며 최대 곡률
0.196 1/m로 경로 형상 검사를 통과했습니다. 실주행 검증은 하지 않았습니다.

이전 11개 체크포인트의 경로 생성 실패 구간은 이번 경로에 포함되지 않습니다.
체크포인트 원본 좌표는 보존하며, 경로 좌표는 연결 가능한 차선 중심에
매칭됩니다. 1번 체크포인트와 선택된 차선 중심의 거리는 약 7.185m입니다.

실행 전 자동 동기화/중간 시작 설정은 유지했습니다. 현재 VTD 원본 XML을
패키지로 동기화했으며, 원본의 Ego 위치나 장면은 수정하지 않았습니다.
Ego (1435.745, 1210.102)의 시작 거리 7.199m, 방향 차이 1.411도로
시나리오 검사를 통과했습니다. 중간 시작 처리에서 제거된 경로점은 0개입니다.

다음 비주행 검사로 실제 실행 전 미션 구간 생성까지 통과했습니다.

```bash
python3 tools/verification/run_scenario.py scenario/mixed/M15 \
  --run-id m15_checkpoint10_check --dry-run
```

검사 결과 그림은
`output/verification/M15/m15_checkpoint10_check/mission_corridor.svg`에 있습니다.
VTD 연결/주행은 수행하지 않았습니다.
