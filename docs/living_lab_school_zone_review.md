## 보류 2개에 필요한 정보

### 15번

현재 두 좌표는 같은 방향의 서로 다른 차로다. 전 구간의 두 차로를 모두 보호구역으로 보는지, 한 차로의 경계 캡처가 잘못 짝지어진 것인지 전체 차로 지도만으로 구분되지 않는다.

필요한 자료는 **road 1769의 S 약 25~54 부근에서 보호구역 시작·끝이 보이는 VTD 확대 화면**, 또는 해당 구간에 적용할 차로와 시작/끝 S다. 도로 전체를 보호구역으로 넓히거나 대각선 연결을 감점 영역으로 사용하지 않았다.

### 28번

현재 경계 쌍은 중앙선을 사이에 둔 반대 방향 차로다. 유턴 경로를 만들어 연결하면 보호구역 밖을 감점 영역으로 포함할 수 있다.

필요한 자료는 **road 2386 lane +1 쪽 보호구역의 반대쪽 경계가 보이는 VTD 확대 화면**, 또는 올바른 끝점의 road/lane/S다. 29번의 +2 차로가 연결된다고 해서 +1 차로의 경계까지 동일하다고 가정하지 않았다.

이 둘을 제외한 43개에서는 보호구역 진입과 속도 채점이 가능하다. 둘의 범위가 미확정이므로 미지정 위치를 모두 ‘보호구역 아님’으로 처리하지 않고 부분 평가 상태를 유지한다.

## 검증과 적용

- 수정 좌표의 World→road S 오차는 모두 0.001m 미만이다. 원본을 포함한 전체 최대 오차는 약 0.00584m다. **지도 내부 일치도이지 실세계/공식 경계 정확도가 아니다.**
- 복구된 모든 도로·차로 구간의 중간점 검출, 범위 밖/반대편 차로 제외, 경계 입력 순서 반전, 미해결 두 쌍의 잘못된 우회 연결 방지, 원본 보존과 다른 원본에 대한 보정 거부를 테스트했다.
- 기본 평가 설정에 보정 파일이 연결되어 있다. 웹 서버 재시작 시 43개가 로드된다. 제어 감지기는 서버가 새로 출력하는 명령으로 다시 실행한다.
- 실제 VTD 주행에서 신호/객체/영상까지 포함한 전체 검증은 별도다.

```bash
python3 tools/map_extraction/audit_school_boundaries.py --corrected
python3 -m unittest discover -s tests -p 'test_school_zone_review.py'
```

첫 명령은 `43 accepted 2 pending 77 ranges`를 출력해야 한다. 웹의 보호구역 검증 정보에도 수정 근거와 펼쳐진 구간을 포함한다.
