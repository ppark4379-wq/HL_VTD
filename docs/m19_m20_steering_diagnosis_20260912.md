# M19-1 전역경로 실패 / M20 복귀 급조향

## 확인한 원인

- M19-1의 사전 계산된 차선 연결 그래프는 존재했다. 실패한 것은 현재 장애물과 차량 체적을 반영하여 실제 추종할 전역 궤적을 만드는 단계였다. 기존 실행 마지막 기록에는 `search_failed=true`, 전역경로 0점, `1172 -> 1139` 연결부의 `source_join_not_smoothable_inside_corridor`가 남아 있다.
- 연결부의 짧은 샘플 간 yaw 불연속은 일반적인 연속 급커브와 다르게 분류됐다. 연속 급커브에는 긴 연결 구간과 여러 접선 길이를 탐색하면서, 불연속 연결부에는 3/5/8m 구간과 접선 배율 1만 허용했다. 실제로는 통과할 수 있는 연결을 제한된 후보만 보고 실패시켰다.
- 그 뒤 기하 연속성 보조 판단은 차량이 경로에서 12m까지 벗어나고 잔여거리가 0이어도 이전 경로를 인정했다. 경로 투영은 종점에서 거리를 고정하므로 종점을 지나도 이 조건이 계속 참이었다. M19-1은 곡률 0인 소진된 경로를 따라 중앙섬 쪽으로 진행했다.
- M20은 짧은 이전 경로의 끝점이 차량 옆/뒤에 남은 상태에서 Pure Pursuit가 이를 계속 목표로 삼았다. 기존 로그의 조향 요구가 약 -1.5rad까지 증가해 실제 명령 제한 0.48rad에 걸렸다. 조향 제어기의 응답 속도만 올려 해결할 문제가 아니다.

## 수정

- 짧은 연결부도 연속 급커브와 동일한 연결 길이·접선 후보를 검사한다. 차량 곡률 한계, 차량 체적의 주행면 포함 여부, 노면표시, 장애물 검사는 유지한다. 시나리오 ID에 따른 분기는 없다.
- 이전 경로를 유지하려면 현재 자세에 붙어 있고 전방 구간이 남아 있어야 한다. 크게 이탈하거나 종점을 지난 경로는 검증된 복귀 경로의 대상으로 처리한다.
- Pure Pursuit가 가까운 종점에 도달하면 조향을 0으로 정리하며, 뒤에 남은 종점을 계속 추종하지 않는다. 지역 경로 종점 도달을 미션 완주로 오인하거나 다음 경로 없이 순항속도로 되돌리는 처리를 제거했다. 기존 게이트웨이 복귀, 대기, 시뮬레이션 정체 탈출은 유지한다.

## 검증

- 기존 M19-1 30초 차량 자세와 마지막 수신 객체를 조합한 진단 재생: 수정 전 전역경로 0점 / 탐색 실패 → 수정 후 173점 / 게이트웨이 도달 / 장애물 검사 승인. 객체는 해당 과거 시점의 전체 관측 이력이 아니므로 이 결과만으로 실제 주행 성공을 주장하지 않는다.
- 실제 VTD M19-1: `m19_join_verify_20260912_0238`, 61.819초 완주, 충돌 0프레임, 최대 조향 요구 0.354237rad, 조향 포화 0프레임. 도로 순서 `100 -> 1172 -> 1139 -> 1145 -> 211 -> 679 -> 208 -> 3261`. planning 처리시간 95백분위 0.294ms.
- 실제 VTD M20: `m20_steering_verify_20260912_0240`, 85.275초 완주, 최대 조향 요구 0.376924rad, 조향 포화 0프레임. 대기 후 복귀하여 `126 -> 2426 -> 1094 -> 1043` 통과. 기존에 요청된 시뮬레이션 접촉 진행으로 충돌 157프레임이 기록됐으며, 무충돌 성공으로 분류하지 않는다.
- 실제 VTD M19: `m19_inline_verify_20260912_0245`, 60.060초 완주, 충돌 0프레임, 최대 조향 요구 0.358881rad, 조향 포화 0프레임. M19-1과 동일한 회전교차로 도로 순서를 통과했다. 첫 두 파일 경로 로드는 VTD 등록 단계에서 실패했으며, 같은 패키지의 XML을 직접 전달한 실행에서 검증했다. 완주는 정지선 준수까지 입증하는 지표는 아니며, 이후 사용자 지적에 따라 횡단보도 정지 위치는 별도로 분석한다.
- 일반적인 회전 궤적에 짧은 yaw 불연속을 넣은 회귀검사: 이전 탐색 조건으로 재빌드한 비교 실행은 `mapped turn lost all tracking geometry`로 실패하고, 수정 후 통과했다. 종점 통과/여러 차량 방향/전방 구간 유지 검사와 기존 대기·복귀·접촉 진행 검사를 포함한 관련 CTest 12개 통과.
