# M16 정적 복구와 신호 횡단보도 정적 전환

사용자가 정한 시뮬레이션 정책에 따라 객체 종류를 추가하지 않고, 실제 이동·연속 정지 관측을 기존 복구 판정에도 일관되게 적용했다. 특정 시나리오 ID나 좌표를 사용하지 않는다.

## 동작

- 횡단 중이면 계속 제동한다. 정지 시간 초과만으로 움직이는 객체의 제동을 해제하지 않는다.
- 움직이다 멈춘 객체는 `stopped_dynamic_confirmation_time`(현재 0.75초) 동안 연속 정지를 확인하면 횡단보도 전체 대기에서 정적 회피로 전환한다. 기존 보도 밖 동작에 더해 신호 횡단보도에도 적용한다.
- 다시 움직이면 해제를 취소하고 제동한다. scalar speed 외에 관측 속도 벡터·위치 이동 이력을 사용한다. 관측 누락 시간은 정지 확인으로 누적하지 않는다.
- 정적 전환은 객체를 삭제하는 동작이 아니다. 차량 폭과 객체 OBB를 고려한 회피를 우선한다. 회피가 모두 실패하면 사용자가 지정한 기존 시뮬레이션 저속 접촉 진행 정책이 소형 정적 물체에도 적용된다.
- 적색·황색 정지와 점멸 적색의 범퍼 기준 정지 의무는 독립적으로 유지한다. 점멸 적색에서도 움직이다 정적으로 전환된 객체는 회피 대상이 되지만 신호 정지 의무를 생략하지 않는다.
- 처음부터 정적인 횡단보도 객체의 기존 대기 정책은 이번 '움직이다 정지' 전환과 별개로 유지한다. 처음부터 정적인 객체의 점멸 적색 대기를 통째로 제거한 변경은 아니다.

## M16 반복 정지 수정

`recoveryProtectedObject`, 복구 탐색 후보의 `protectedActor`, 정적 접촉 제동 판정에 중복돼 있던 소형 객체의 영구 보호 예외를 시뮬레이션 정적 확정 정책에 맞췄다. 객체가 다시 움직이거나 정적 확인이 끝나지 않았다면 복구가 제동을 무시할 수 없다.

복구가 동적 위험으로 취소돼도 후보 탐색 순번을 보존한다. 경로가 막힌 상태에서는 속도 추정값뿐 아니라 실제 위치 정체 시간도 복구 활성화에 사용한다. 미션 변경·리스폰·잘못된 자세 입력의 초기화와 신호/실제 위험의 정지 우선순위는 유지한다.

## 검증

- `hl_vtd`, `controller_logic_tests`, `replay_corridor_scene` 빌드 완료.
- 관련 CTest 9개 전부 통과. 기존 검사를 확장해 신호 횡단보도의 0.75초 정적 전환, 녹색 및 점멸 적색에서 OBB 충돌 없는 실제 회피 경로, 재이동 제동, 적색·황색 정지 유지, 관측 누락, 소형 정적 접촉 복구, 위치 고정·속도 추정 불일치를 검사했다.
- M16 실제 정지 기록을 현행 코드로 300프레임 재생: 활성화 후 281프레임에서 복구 명령, 동적 위험에 의한 복구 취소 0회, 마지막 plan_valid=1, target_speed=1.388888889m/s(5km/h), progress_recovery=1.
- 전역 회피 성공으로 결과를 바꿔 기록하지 않았다. 같은 장면은 여전히 완전한 회피 경로를 찾지 못하며 접촉 가능 복구 경로를 명령한다. 이것이 사용자가 요청한 최후 진행 정책이다.
- 고정 위치 장면 재생으로 제어 판단을 검증한 결과다. 수정 후 VTD를 다시 켜 실제 차량 운동·전체 완주를 확인한 것은 아니다. 마지막 게이트웨이에 대한 별도 실패 장면까지 동일 원인이라고 단정하지 않는다.
