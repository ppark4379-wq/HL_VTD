# 황색 정지와 적색점멸 정차·보행자 대기

- 황색(`state=2`)은 적색(`state=1`)과 동일한 정지선 목표·제동 권한을 사용한다. 기존의 황색 통과 결정과 해당 상태 캐시는 제거했다.
- 점멸은 앞범퍼 기준 정지선 앞 0~2m에서 연속 0.5초 정지해야 해제한다. 정지선을 지난 위치, 너무 먼 위치, 움직이는 프레임은 시간을 누적하지 않는다. 여러 짧은 정지를 합산하지 않으며 지연된 한 프레임으로 정지 시간이 충족되지 않게 한다.
- 같은 정지선에서 한 번 정지 요건을 충족하면 다시 요구하지 않는다. 다른 정지선, 명시적인 신호 모드 변경, 리스폰은 별도로 처리한다. 미할당 패킷 한 번으로 이미 충족한 정지가 취소되지 않는다.
- 횡단보도에 보행자가 남아 있으면 정지 시간을 채운 뒤에도 대기한다. 보행자 체적 전체가 벗어나고 기존 횡단보도 해제 여유 시간이 지난 뒤 출발한다. 이 대기에는 시뮬레이션의 정적 객체 대기 시간 초과 해제를 적용하지 않는다.
- 현재 GT 인터페이스의 `state=6`은 적색/황색 점멸을 구분하지 않는다. 실제 설정의 적색점멸 ID 목록도 비어 있었다. 따라서 색이 지정되지 않은 점멸에도 보수적으로 동일한 정지·양보 정책을 적용한다. 점멸 색상 자체를 판별했다고 주장하지 않는다.

`stop_hold_time` 기본값과 설정값을 0.5초로 맞췄으며 로더는 0.5초 미만 및 비유한 값을 거부한다. 기존 조향, 게이트웨이 복귀 및 시뮬레이션 접촉 진행 정책은 유지한다.

회귀검사는 가까운/먼 황색에서 적색과 같은 정지 요구, 0~2m 경계, 연속 정지 시간, 이동 시 초기화, 지연 프레임, 다른 정지선, 수신 공백, 빈 횡단보도 출발, 정지 보행자 장시간 대기, 보행자 체적의 완전한 통과를 검사한다. 관련 CTest 8개 통과.

실제 VTD M19 실행 `m19_yellow_stop_verify_20260912_0301`: 황색 최초 수신 시 정지선까지 2.8769m에서 즉시 제동했고, 정지선 앞 1.4688m에 정차했다. 기록된 차량 OBB의 최전방점과 지도 정지선의 직접 거리도 1.4689m로 일치했다. 녹색 후 출발하여 61.822초에 충돌 없이 완주했다. 적색점멸과 보행자 조합은 생산 플래닝 경로를 사용하는 회귀검사로 확인했으며, 이번 VTD 재주행에서 해당 신호·보행자 조합까지 관측한 것은 아니다.
