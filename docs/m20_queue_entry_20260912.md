## 재현으로 확인한 결함

전역 탐색은 앞차 뒤 5차선까지의 안전한 대기 경로를 실제로 생성했다. 그러나 대기 접근은 전체 게이트웨이 통과 실패 상태로 저장되므로 약 1초 후 다시 전역 탐색했다. 이때 같은 장애물에 대한 새 **대기** 경로도 기존 경로에 무조건 덮어썼다. 차량이 진행한 뒤 새 출발점에서 재탐색하면서 차선 변경 곡선이 계속 달라졌다. 같은 장면의 0초 자세에서는 x≈700에서 5차선 중심에 도달하는 경로가, 10초 자세에서는 같은 x에서 아직 4차선인 경로로 다시 만들어졌다. 늦게 옆 차선에 도달하면 완전한 대기 차선 진입이 충돌/주행면 검사에서 탈락하고 옆 차선의 짧은 대기 경로만 남았다.

또한 안전한 대기 경로가 선택되어도 로컬 우회 트리거는 그 끝을 넘어 기존 차선의 앞차를 다시 검사했다. 대기 접근이 이미 해결한 문제에 별도 우회 탐색을 반복했다.

초기 실제 실행의 전체 판단 이력은 없으므로 이것이 모든 프레임의 유일한 원인이었다고 단정하지 않는다. 위 결함은 생산 코드의 시간순 자세 재생 및 별도 회귀검사로 확인했다. 객체는 보존된 정지 차량/자전거 관측으로 재구성했고, 기록 자세 재생은 새 조향에 반응하는 폐루프 주행이 아니다.

## 수정

- 같은 장애물·같은 관측에서 현재 자세와 연결되고 안전한 대기 접근은 재탐색 후에도 유지한다. 이미 시작한 차선 변경을 새 곡선으로 계속 미루지 않는다.
- 옆 차선의 임시 대기에서 실제 진입 차선 대기로 개선되는 경로는 교체한다. 장애물 변화, 연결 상실, 안전성 실패 때도 재계획은 계속 가능하다.
- 유효한 전체 게이트웨이 통과 경로가 새로 생기면 기존처럼 즉시 우선 채택한다. 거리 기준으로 우회와 대기를 나누지 않는다.
- 안전한 대기 경로 끝의 장애물만으로 별도 로컬 우회를 시작하지 않는다. 선택 경로 위의 실제 위험과 위치 이탈 복귀 트리거는 유지한다.
