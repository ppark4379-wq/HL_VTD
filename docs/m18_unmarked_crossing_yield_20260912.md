# M18 횡단보도 밖 이동 객체 대기 및 정지 후 회피

기존 `crossingObjectRequiresEmergency`는 현재 속도의 정지거리 안에 있는 횡단 객체를 검사한다. 차가 제동해 속도가 낮아지면 검사 범위도 줄고, 객체가 아직 횡단 중이어도 순간 제동 조건이 사라질 수 있다. 지도 횡단보도 점유 처리는 별도로 존재하지만 횡단보도 밖 횡단 전체를 기억하지 않는다.

이번 변경은 현재 추종 기준 경로 앞에서 접근·횡단하는 작은 객체를 ID별로 추적한다. 신호나 횡단보도 표식 유무와 관계없이 이동을 감지하면 긴급제동에 반영하고, 제동 당시 차선의 위치·방향·폭을 보존한다. 차가 멈추거나 경로가 바뀌어도 객체 몸체 전체가 통과할 때까지 대기한다. 원래 쪽으로 되돌아가 위험이 사라진 경우에도 해제한다.

객체가 멈추면 기존 `stopped_dynamic_confirmation_time`(0.75초) 동안 연속 정지를 확인한 후 횡단 대기를 해제하고 정적 회피에 맡긴다. 실제 출발에는 기존 비상제동 해제 유지 시간이 적용된다. 관측 속도 벡터와 위치 변화도 확인하므로 scalar speed만 0인 이동 객체를 정적으로 오인하지 않는다. 짧은 관측 누락은 이동 이력을 유지하며, 누락 시간을 정지 확인 시간으로 계산하지 않는다. 다시 움직이면 횡단 대기를 재개한다.

객체를 충돌 검사에서 지우지 않으며 보행자 크기 객체와의 접촉 금지도 유지한다. 기존 신호 정지·지도 횡단보도 점유·적색점멸 대기 조건은 유지한다. 특정 M18 좌표나 객체 ID는 사용하지 않는다. 기존 경로의 제한된 전방 구간을 검사하며 새로운 전역 탐색 주기를 추가하지 않는다.

검증: `hl_vtd`, `controller_logic_tests` 빌드 완료. 신규 `unmarked_crossing_yield`를 포함해 제어 회귀 검사 10개 통과(6.34초). 신규 검사는 이동 시작, 정지한 Ego의 지속 대기, 몸체 일부가 남은 경우, 연속 정지 후 충돌 없는 회피 경로, 재이동 제동, 복수 객체, 관측 누락, 평행 이동·원거리 객체 제외, 큰 dt로 확인 시간을 건너뛰지 않는 조건을 포함한다. VTD 재실행은 하지 않았으며 결과는 오프라인 검사다.
