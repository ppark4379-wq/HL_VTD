## 잔상 및 조향에 대한 구분

- `runWorldProcess()`는 매 수신 프레임의 객체로 WorldState를 새로 만든다. 정지 이력은 ID·시간·최근 위치이며 과거 OBB들을 누적해서 길을 막는 구조가 아니다. 이번 오토바이 10은 계속 이동 속도로 수신됐다. 주원인을 ‘동적 객체의 정적 잔상’으로 설명할 근거는 없다.
- 객체 15/16/17/14는 시나리오의 굽은 횡단 경로를 실제로 이동한 뒤 경로 끝에 멈춘다. 예를 들어 17은 `(422.388, -35.357)`, 14는 `(435.9432, -27.5604)`에서 속도 0으로 계속 수신됐다. 이 물체를 정적으로 회피하는 것 자체는 기존 정책과 일치한다. 이동 흔적 전체가 물체로 남는 것과 다르다.
- 204.533초 객체 16, 219.372초 객체 17은 같은 프레임에 body_cleared와 motion_started가 함께 기록됐다. 저장한 횡단 평면으로 해제한 직후, 변경된 참조 경로로 다시 검사해 등록할 수 있다.
- 186.292~201.052초 사이 동적 회피 경로 materialized와 safe_gateway_tracking_resumed가 12쌍 반복됐다. 특히 196.852~200.932초에는 회피 선택 11회가 일어났다. 횡단 대기로 실제 움직이지 않는데 미래 충돌을 피하는 기동을 선택하고, 정지 속도에서 안전해 보이는 기존 경로로 바로 되돌리는 판단이 충돌한다. ‘materialized’라는 로그 이름도 전체 전역 경로 교체와 혼동하면 안 된다. 이 로그에서는 기존 702점 전역 경로가 유지됐다.
- 이 반복은 조향 기준 변경을 만들 수 있는 결함이다. 다만 이번 실행의 165~240초 실제 자차 궤적에서는 사용자가 표현한 큰 좌우 왕복이 그대로 재현되지는 않았다. 해당 구간의 반복 정지와 내부 경로 선택·해제 반복은 직접 확인했다. 모든 조향 흔들림을 이 원인 하나로 확정하지 않는다.

## 권장 수정 범위

1. 객체 종류를 새로 구분하지 않고, 관측 이동 벡터·선택 경로의 접선·전후 간격으로 같은 방향 선행과 실제 횡단/진입을 나눈다. 같은 방향 선행은 ACC에 맡기고 현재 충돌·끼어들기·급제동 EBS는 유지한다. 보도 밖 대기와 지도 횡단보도 점유에 동일한 관계 기준을 적용한다.
2. 횡단 대기는 실제 충돌 구역에 접근·점유하는 동안 유지한다. 몸체가 위험 구역을 벗어나면 해제하고, 경로가 바뀌었다는 이유만으로 완료한 횡단을 즉시 재등록하지 않는다. 이후 새 접근이 관측되면 다시 제동한다. 움직이다 멈춘 객체의 연속 0.75초 정적 전환은 유지한다.
3. 횡단 대기 중 동적 회피의 선택→원복 반복을 막는다. 정적 장애물과 게이트웨이 연결 탐색은 계속하되, 출발 시 현재 자세에서 안전성을 확인한 경로를 일관되게 채택한다. 전체 캐시 삭제나 게이트웨이 복귀 로직 제거로 해결하지 않는다.
4. 실제 위험/신호 대기가 해제되고, 정지 상태에서 유효한 양의 목표가 나온 경우에만 잔류 제동 상태를 정리한다. 주행 중 제동 능력과 조향 변화율 제한은 유지한다. ACC에는 10/15km/h 강제 하한을 적용하지 않는다.
