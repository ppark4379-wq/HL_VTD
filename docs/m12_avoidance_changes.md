2. **안전한 복귀**: 실제 사용할 후속 경로를 충돌 검사한 뒤 회피를 종료한다. 후속 경로가 위험하고 현재 회피 꼬리가 안전하면 그 꼬리를 보존한다. 장애물을 반드시 추월했거나 한 명목 차선에 차체 전체가 들어와야만 상태가 끝나는 조건은 넣지 않는다.

4. **장애물/높이 판정**: 수신 정적 객체를 크기나 현재 ego와의 높이 차이로 전역 탐색에서 빼지 않는다. 후보 도로의 객체 위치 노면 높이를 비교하여 내리막 객체를 포함하고 실제 다른 층만 제외한다. 전역 곡선의 빠른 충돌 사전검사는 5차 곡선 전체를 감싸는 Bezier hull과 차량 크기를 사용하며, 가까운 객체는 실제 곡선으로 검사한다.
5. **경로 존재와 주행 승인 분리**: 막힌 기본 경로는 회피 탐색의 참고용으로 보관하되, 안전한 복귀 경로라는 이유로 승인하지 않는다. 실제 선택 경로가 막히면 최소속도 규칙 뒤에 제동거리 속도 상한을 적용하고 재탐색한다. 경로를 삭제하거나 새 EBS 잠금을 만들지 않으며 막힘 해소 시 다시 계산한다.
6. **정지선 전 정렬**: 물리적인 정지선 거리에서 앞범퍼와 정지 여유를 뺀 거리 안에 정렬해야 한다. 이 조건이 있는 게이트웨이 후보에서는 짧은 중간 기동보다 남은 차선 변경 단계가 적은 후보를 우선한다. 장애물 회피 후보를 정지선 거리만으로 전부 금지하지 않는다.

## 후속 수정: 전역 탐색 그래프의 회피 연결 누락

M12를 VTD에서 한 차례 240초 실행해 기록한 뒤, 동일 입력을 고정하여 수정 전후 비동기 전역 플래너를 비교했다. 수신 객체가 이미 존재했고, 전역 생성 실패가 주원인이었다. 125–129초에는 실제로 안전한 기존 회피 기동을 유지한 다음 새 전역경로를 추종하는 승계가 확인됐다.

### 확인된 원인과 수정

1. **전역에는 인접 차선 12m 곡선만 있었다.** 로컬의 20/30m 후보 설정이 전역 그래프에는 적용되지 않았다. 12m에서 차체 앞 모서리가 노면 밖으로 나가는 곡선도 중·장거리에서는 가능했다. 기존 추종용 `forward/reverse` 그래프는 유지하고 별도 `globalLateral`에 기존 설정의 12/20/30m 및 다차선 연결을 추가했다.
2. **출구 차선에 도착하기 전 옆 여유 면으로 빠지는 연결이 없었다.** 교차로 커넥터의 실제 종방향 후속 도로를 따라 앞쪽 출구의 옆 차선으로 연결한다. 임의 XY 근접 도로, 다른 회전 방향, 다른 목표는 추가하지 않는다. 전체 차체가 기존 허용 면/제한된 surface-only 면에 있어야 한다.
3. **밀집부에서 세 차선 복귀를 세 번으로만 나누었다.** 인접 차선마다 12m를 쓰면 남은 약 26m에서 36m가 필요했다. 모든 중간 경계의 변경이 허용된 경우 여러 차선을 하나의 곡선으로 연결한다. road ID 경계에서는 실제 successor를 따라간다. 명목 장애물 여유 0.30m를 줄이지 않고도 기록된 밀집 장면의 경로가 생성된다.
4. **새로운 무효 후보가 기존 안전한 후보를 가릴 수 있었다.** 선택 후 실패할 때마다 A*를 다시 실행하는 32회 제한이 코너를 자르는 유사 후보들로 소진됐다. 확장 시 실제 5차 곡선의 20/50/80% 지점에서 차체 모서리의 노면 포함을 먼저 확인하고 캐시한다. 이 검사는 빠른 필요조건일 뿐이며, 선택 후 기존의 촘촘한 차체·차선 규칙·장애물 최종 검사를 생략하지 않는다.

### 계산량과 안정성

- 경로 비용상 이미 열등한 연결은 곡선/충돌 검사 전에 제외한다.
- 같은 차선 안의 offset 이동 목적점은 주행 전 계산한다. A* 상태마다 반복하던 그래프 순회와 set 할당을 제거했다.
- 전역 탐색은 기존 비동기 worker에서 실행한다. 재탐색 실패 상한을 늘리거나 제어 루프에서 전수 탐색하지 않는다.
- 막힌 동일 전역경로에 대한 실패 재연결만 최대 0.5초 캐시한다. 실제 관측 객체, 차량 이동, 경로/미션 변경 시 무효화한다. 성공 경로의 안전 검사는 계속 수행한다.
- 조향 제어기, 신호등·보행자 규칙, 명목 장애물 여유 및 시나리오별 주행 설정은 이번 탐색 수정에서 변경하지 않았다. 앞서 요청한 M12 surface-only 실험은 별도이며, 새 탐색 함수에 M12/R2423 등 ID 분기는 없다.
