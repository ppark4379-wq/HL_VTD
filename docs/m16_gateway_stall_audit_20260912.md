## 별도로 재현한 정지 가능 조건

- **속도 추정값과 실제 위치 진행 불일치:** 위치를 고정하고 추정 속도를 0.2m/s로 유지하면, 정지 기준 0.55km/h≈0.153m/s를 초과하여 `blockedTime`이 매번 0이 된다. `noMotionTime`은 늘어나지만 복구 활성화 조건에 사용되지 않는다. 전역·지역 경로가 막힌 합성 장면에서 전체 플래너와 최종 제어기를 거친 재출발 검사가 실패했다. 이번 실차량 로그의 직접 원인은 아니다.
- 위 조건에 `blocked && noMotionTime >= timeout`을 추가한 별도 실험에서는 같은 검사에서 양의 목표속도와 양의 최종 가속 명령이 나왔다. 정상 저속 진행과 위치 노이즈를 오판하지 않도록 fresh telemetry, 실제 누적 전진량, 정지 원인을 함께 검사하는 보강이 필요하다.
- 정적 소형 물체 접촉/진입도 복구의 크기 예외 때문에 막힌다. 동일 크기의 물체를 사용한 독립 장면에서 재현했다.
- 정상 대형 정적 차량의 게이트웨이 막힘, 지도/경로 부재, 소모된 경로 끝, 동적 위험 해소 후 재출발은 기존 검사에서 통과했다. 따라서 '정적 차량 하나가 게이트웨이를 막으면 항상 복구가 안 된다'고 결론낼 수 없다.
- 적색/황색 정지선 대기, 점멸 적색의 정지 의무, 실제 횡단/동적 충돌 위험, 비유한 자세·통신 두절, 미션 완료 정지는 별도 권한이다. 원인이 유지되는 정지를 단순 시간 초과로 없애면 이전 M18 긴급제동 문제가 재발한다.
- 횡단보도 안에서 한번 움직인 객체는 정지하더라도 통과 완료까지 점유 대기를 유지하는 코드가 있다. 이는 보도 밖에서 멈춘 객체의 정적 회피 전환과 다르다. 위험/점유가 남아 있는지와 오래 기다렸다는 사실을 구분해야 한다.

## 수정안과 다른 시나리오 영향

권장안은 기존 정상 전역 경로와 게이트웨이 선택을 유지하고, **복구 분기 안의 분류·재시도·진행 감시를 바로잡는 것**이다.

1. 정적 시설물과 실제 보행자·자전거 이용자를 크기 하나로 동일 취급하지 않는다. 현재 9910 GT의 ObjectState에는 category/type이 없다. 이미 연결하는 표준 RDB 스트림의 category/type을 객체 ID 및 동일 프레임 기준으로 보완하면 기존 GT 패킷 규격을 바꾸지 않고 구분할 수 있다. RDB의 COMMON/OPENDRIVE 시설물 여부와 연속 정적 관측을 확인하고, 실제 이동 또는 움직임 이력이 있으면 동적 위험 검사로 되돌린다. 객체 종류가 미상인 경우를 무조건 시설물로 간주하지 않는다.
2. 정적으로 확정된 시설물은 차량과 동일한 시뮬레이션 복구 정책을 적용한다. 충돌 없는 경로가 최우선이고, 모두 실패했을 때만 기존 저속 접촉 진행 분기를 사용한다. 실제 보행자 대기·동적 EBS·신호 정지는 유지한다.
3. 일반 경로의 실제 위험과 복구 후보 하나의 부적합을 구분한다. 후보 거부 후에는 현재 장면으로 재검사하며 다음 후보 순번을 유지한다. 저장 경로의 안전 판정이나 과거 객체 상태를 무검증으로 재사용하지 않는다. 미션 변경·리스폰에서만 탐색 범위를 초기화한다.
4. 신선한 위치 기록으로 실제 전진 정체를 함께 감시한다. 경로가 막혔는데 속도 추정값만으로 타이머가 영원히 초기화되는 구멍을 닫는다. 신호/보행자/실제 EBS에는 이 감시가 출발 권한을 주지 않는다.
5. 마지막 제어 명령까지 검사한다. 목표속도만 양수가 되는 것으로 성공 판정하지 않고 plan_valid, emergency, 최종 target_accel과 이후 위치 진행을 확인한다. 복구 위험 객체 ID·판정 근거·후보 순번도 로그에 남겨 반복 원인을 구분한다.

**크기 예외를 통째로 삭제하는 수정은 적용하지 않는 것이 맞다.** 별도 실험에서 이번 장면은 300프레임 재생 후 target_speed=1.3889m/s, plan_valid=1, progress_recovery=1로 바뀌었다. 그러나 기존 정지 보행자 보호 검사가 실패했다. 영향이 없다고 주장할 수 없는 변경이다. 현재 정상적으로 생성되는 다른 시나리오의 전역 경로 후보 수나 게이트웨이 권한을 넓히는 방식도 이번 원인의 직접 해결책이 아니다.
